# Aether 学习练习

这些练习按风险从低到高排列。每完成一个练习，都先写测试，再改业务代码，最后运行 `pnpm quality`。

| 练习 | 文件范围 | 验收标准 |
| --- | --- | --- |
| 会话平均 RSSI | `selectors.ts`、`tests/` | 空会话返回 `null`；有样本时返回确定性平均值。 |
| 设备展示名称 | `selectors.ts`、设备页 | 设备无名称时显示短标识符；不修改导出原始数据。 |
| 显示偏好 | `types.ts`、设置页 | 新偏好有默认值，旧数据 hydrate 后仍可用。 |
| 原生失败路径 | `TrackingController`、测试 | 原生启动失败时会话被停止并显示可读错误。 |
| 观测健康状态 | 端口、状态机、首页 | 显示最后 BLE 观测时间；不在 UI 中直接读原生模块。 |

> 不要一开始就修改 `NativeTrackerService.ts`。先从纯函数和 reducer 学起；它们不需要真机，失败也更容易定位。
